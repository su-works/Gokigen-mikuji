# ごきげんみくじ

神社のおみくじのような見た目で、読むとちょっと笑える Web おみくじアプリです。
ボタンを押すと、運勢・メッセージ・ラッキーアイテム・今日のミッションがランダムに表示されます。

- 公開URL：https://su-works.github.io/Gokigen-mikuji/
- 使用技術：HTML / CSS / JavaScript（ES Modules）、GitHub Pages
- 運勢の種類：全15種（Ver.1.0 の抽選対象は14種）

## コンセプト

- 世代を問わず楽しめる、ポジティブで少しシュールなおみくじ
- 神社らしい言い回しと見た目を残しつつ、読むと少し笑える
- 無理にテンションを上げず、真面目そうな文章がよく読むとちょっとおかしい、というギャップを大切にする
- どんな結果でも、最後は前向きになる

## 機能（Ver.1.0）

| 機能 | 内容 |
|---|---|
| TOP画面 | 抽選前は枠つきのTOP（タイトル・案内文・ボタン）。引いた後は、タイトルと枠を隠して「もう一度引く」ボタンだけ残す |
| おみくじを引く | ボタンを押すと抽選し、結果カードを表示する。2回目以降は「もう一度引く」に変わる |
| 2段階の抽選 | カテゴリー抽選 → カテゴリー内の運勢抽選（詳細は「抽選仕様」） |
| 結果表示 | 図鑑No.、運勢名、キャラクター画像、一言、メッセージ、ラッキーアイテム、今日のミッションを表示 |
| カテゴリー別の見た目 | 通常・特別枠・幻想生物・超レアで、カードの枠や配色を切り替える |
| おまけ表示 | おまけつき吉のとき、ラッキーポーズと謎のスタンプを表示する |
| 箱を開ける演出 | サプライズ吉のとき、箱の画像をタップするまで中身を隠す |

## 抽選仕様

### 1. カテゴリー抽選（第1抽選）

0以上100未満の乱数を作り、出現率を足し合わせながら、どの範囲に入るかでカテゴリーを決めます。出現率は `main.js` の `categoryRates` に1か所でまとめて管理しています。

| カテゴリー | 内部名 | 出現率 | 種類数（Ver.1.0） | 1種あたり |
|---|---|---|---|---|
| 通常吉 | `normal` | 90% | 8 | 11.25% |
| 幻想生物 | `fantasy` | 6% | 3 | 2% |
| 特別枠 | `special` | 3% | 2 | 1.5% |
| 超レア | `ultra_rare` | 1% | 1 | 1% |

### 2. 運勢抽選（第2抽選）

選ばれたカテゴリーの中から、均等な確率で1種を選びます。この2段階にしているので、あるカテゴリーの種類を増やしても、カテゴリー全体の出現率は変わりません。

### 3. 表示内容の抽選

- ラッキーアイテムと今日のミッションは、各運勢が持つ候補（各6個）から毎回1つずつ選ぶ
- おまけつき吉のラッキーポーズと謎のスタンプは、それぞれ独立して1つずつ選ぶ
- メッセージは運勢ごとに固定（全行を表示する）

### 4. 抽選から除外している運勢

おみくじミックス吉（`SP_001`）は、Ver.1.0 では抽選対象から外しています。データは残したまま、`filter()` で抽選用の配列から取り除いています。

```javascript
const drawTargets = fortunes.filter(item => item.id !== "SP_001");
```

## データ構造
運勢データは `js/data.js` の配列 `fortunes` で管理しています。内容（データ）と処理（抽選・表示）を分けているので、運勢の追加は基本的に `data.js` に1件足すだけです。キャラクター画像を表示する運勢は、`main.js` の画像の対応表にも1行足します。

| 項目 | 型 | 内容 | Ver.1.0 の結果画面 |
|---|---|---|---|
| `id` | 文字列 | 内部ID。一度決めたら変更しない固定ID | 表示しない（除外判定に使用） |
| `displayNo` | 数値 | 図鑑No.（表示用の通し番号） | 使う |
| `category` | 文字列 | `normal` / `fantasy` / `special` / `ultra_rare` | 使う（抽選・見た目） |
| `specialType` | 文字列 | 特別枠の種類（`mix` / `bonus` / `surprise`）。 | surprise の判定に使用 |
| `name` | 文字列 | 運勢名 | 使う |
| `oneLiner` | 文字列 | 一言 | 使う |
| `message` | 文字列の配列 | メッセージ（1行ずつ） | 使う |
| `luckyItems` | 文字列の配列 | ラッキーアイテムの候補 | 使う（1つ抽選） |
| `missions` | 文字列の配列 | 今日のミッションの候補 | 使う（1つ抽選） |
| `bonuses` | オブジェクト／空配列 | おまけつき吉のみ `{ luckyPoses: [...], stamps: [...] }` | 使う |
| `character`, `characterSettings`, `species`, `appearance`, `ability`, `personality`, `description`, `comment`, `hint` | 文字列／配列 | キャラクター設定・図鑑用の紹介文 | 使わない（図鑑用に保持） |

キャラクター画像のパスは `data.js` ではなく `main.js` に、運勢名をキーにした対応表（`normalImages` / `srImages` / `specialImages`）として持っています。結果表示のとき、運勢名から画像を引いて表示します。

内部ID（変更しない）、図鑑No.（ユーザーに見せる番号）、カテゴリー（抽選・分類用）を分けているので、並び順を変えたり運勢を追加したりしても、既存のデータが壊れにくい構造です。

## 設計の理由

### 2段階抽選にしている理由

運勢を1つの袋に入れて均等に引く方式（1段階）だと、運勢を追加するたびに、レアの出現率が下がってしまいます。

たとえば Ver.1.0 の抽選対象は14種で、ごきげん大明神は 1/14（約7.1%）です。ここに通常吉を12種追加すると 1/26（約3.8%）に下がります。

そこで、先に「どのカテゴリーか」を決め、そのあとでカテゴリーの中から1種を選ぶ2段階にしました。

| 方式 | 運勢を追加したとき |
|---|---|
| 1段階 | 全体の数が増え、レアの出現率も下がる |
| 2段階（採用） | カテゴリーの出現率は固定。変わるのはカテゴリー内の1種あたりの取り分だけ |

カテゴリーの出現率は `categoryRates` の1か所にまとめているので、レア度の調整も1か所で済みます。

### 内部ID・図鑑No.・カテゴリーを分けている理由

| 項目 | 役割 | 変わってよいか |
|---|---|---|
| 内部ID（`N_001` など） | プログラムが運勢を見分ける名札 | 変えない |
| 図鑑No. | ユーザーに見せる番号 | 並べ替えや追加で変わってよい |
| カテゴリー | 抽選と見た目の切り替え用の仲間分け | 追加はできる |

現在のコードでは、内部IDを抽選から除外する運勢（`SP_001`）の判定に、カテゴリーを抽選と枠色の切り替えに使っています。

今後、図鑑機能で「発見済み」を `localStorage` に記録するときは、内部IDで保存する予定です。表示用の番号を名札にしてしまうと、運勢を途中に追加して番号を振り直したときに、保存済みの記録が別の運勢にずれてしまうためです。

## 特別枠の仕様

### おまけつき吉（`specialType: "bonus"`）

巾着袋の画像をタップすると、おまけ枠が開きます。
- ラッキーポーズ：2種類から1つ
- 謎のスタンプ：💮 ✨ 🍡 から1つ
- ポーズとスタンプは、それぞれ独立して抽選する

### サプライズ吉（`specialType: "surprise"`）

箱をタップするまで、運勢の中身を隠します。

| 状態 | 表示 |
|---|---|
| 抽選直後（開封前） | 図鑑No.・閉じた箱の画像・メッセージ全文を表示。運勢名・一言・ラッキーアイテム・今日のミッションは非表示 |
| 箱をタップ（開封） | 運勢名・一言・ラッキーアイテム・今日のミッションが表示される。閉じた箱が開いた箱の画像に変わる |

開封は1回だけで、もう一度引くと新しい抽選になります。

### おみくじミックス吉（`specialType: "mix"`）

Ver.1.0 では抽選対象外です（データは保持）。

## 画面の仕組み

結果カードは1枚で、状態を HTML の `data-` 属性で切り替えています。JavaScript は属性を書き換えるだけで、見た目の切り替えは CSS が担当します。
抽選後はTOP画面に is-drawn クラスを付与し、タイトル・案内文・枠などを非表示にします。

| 属性 | 値 | 用途 |
|---|---|---|
| `data-category` | `normal` / `fantasy` / `special` / `ultra_rare` | 枠の色・背景の切り替え |
| `data-state` | `open` / `sealed` | `sealed`（サプライズ吉の開封前）のとき、`.secret` の要素を隠す |

### カテゴリー別の見た目

| カテゴリー | 見た目 |
|---|---|
| 通常吉 | えんじの二重枠 |
| 特別枠 | 朱色の二重枠 |
| 幻想生物 | 金色の枠（少し太め） |
| 超レア | えんじ地に金の枠、文字は和紙色 |

カードごとに変わる色は CSS 変数（`--frame-color` など）にまとめてあり、カテゴリー別の CSS は、その変数を上書きしているだけです。

### デザイン

「昔ながらのおみくじ」をイメージした、和紙・えんじ・金の配色です。

| 役割 | カラー |
|---|---|
| 背景（和紙） | `#F5EEDC` |
| 文字（墨） | `#2B2420` |
| メイン（えんじ） | `#8E2F3A` |
| 朱色 | `#C8372D` |
| 金色（幻想生物・超レア） | `#B8913A` |

- 見出しは明朝体、本文は読みやすいゴシック体
- 縦書きは運勢名だけにして、本文は横書きにしている（スマホでの読みやすさのため）
- 文字サイズは `clamp()` で画面幅に合わせて変化する
- 背景には薄い水玉模様を配置し、和紙の質感を邪魔しない程度に装飾している。

## ファイル構成

```
├── index.html     画面の構造（結果カードの要素）
├── css/
│   └── style.css  見た目（配色・カード・縦書き・カテゴリー別）
├── js/
│   ├── data.js    運勢データ（15種）
│   └── main.js    抽選・結果表示・箱と巾着袋の開封
├── images/  
│   ├── files/            箱・巾着袋の画像（512px版と高解像度版）
│   └── character-trim/   トリミング済みのキャラクター画像
└── README.md
```

### main.js の主な関数

| 関数 | 役割 |
|---|---|
| `pickRandom` | 配列から1つ選ぶ（共通部品） |
| `drawCategory` | 第1抽選：カテゴリーを決める |
| `drawFortune` | 第2抽選：カテゴリー内から運勢を決める |
| `splitPhrases` | 文章を「、」「。」などの区切りで、文節のかたまりに分ける |
| `setPhrasedText` | 文節ごとの `<span>` にして表示する（折り返しで1〜2文字だけ残るのを防ぐ） |
| `renderFortune` | 抽選結果をカードに流し込む |
| `openSurpriseBox` | サプライズ吉の箱を開ける |
| `openBonusBag` | おまけつき吉の巾着袋を開ける |


## 制作について

### キャラクター画像
- キャラクター画像は ChatGPT で制作し、背景の透過処理も ChatGPT で行いました。

- コーディングは、大部分を AI の支援を受けて進めました。
- コードの仕組みは、ChatGPT と Claude の意見を見比べながら確認し、理解したうえで採用しました。
